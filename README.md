# todo-app

一个纯 HTML / CSS / JavaScript 的**每日待办清单**，不需要任何构建步骤，双击 `index.html` 就能用。

## 功能

- **每天自动一张新清单** —— 数据按日期分组保存，跨天后自动进入新的一天
- **每日重复任务模板** —— 设定固定任务（喝水、运动、读书），每天自动出现，带「每日」标记
- **历史记录** —— 底部列出有记录的日期和完成度（如 `1/4`），点一下即可回看
- **日期导航** —— 顶部 `‹` `›` 翻看前后日期，`今天` 一键回到当天
- **历史只读** —— 过去的日期只能看不能改，避免误操作
- 添加任务、勾选完成、删除任务
- 全部 / 未完成 / 已完成 三档筛选
- 数据保存在浏览器 `localStorage`，刷新不丢
- 平滑动画：添加时滑入、完成时划线、删除时折叠
- 跨零点自动切换到新的一天

## 本地使用

直接双击 `index.html`，或用任意静态服务器打开。

## 数据结构

```js
// 每天的清单
localStorage["daily-tasks-days"] = {
  "2026-11-22": [{ id, text, done, tpl? }, ...],
  "2026-11-23": [ ... ]
}

// 每日重复任务模板
localStorage["daily-tasks-template"] = ["喝水", "运动", "读书"]

// 已注入模板的日期（保证每天只注入一次，删掉的不会被重新塞回来）
localStorage["daily-tasks-seeded-day"] = "2026-11-22"
```

早期版本的单一数组（`localStorage["daily-tasks"]`）会在首次打开时自动迁移到当天，不会丢数据。

## 已知限制

数据只存在**当前浏览器的 localStorage** 中：

- 换浏览器、换设备 → 看不到原有数据
- 清理浏览器数据 → 清单会被清空
- 没有多端同步

需要跨设备同步的话，得接入后端数据库。
