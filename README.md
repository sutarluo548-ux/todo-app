# todo-app

一个纯 HTML / CSS / JavaScript 的待办事项应用，**不需要任何构建步骤**，双击 `index.html` 就能用。

## 功能

- 添加任务、勾选完成、删除任务
- All / Active / Completed 三档筛选
- 数据保存在浏览器 `localStorage`，刷新不丢
- 平滑动画：添加时滑入、完成时划线、删除时折叠

## 在线预览

## 本地使用

直接双击 `index.html`，或用任意静态服务器打开。
